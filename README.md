# LifeOS — Regrets of a Lifetime

An anonymous platform for sharing life regrets. Dark, melancholic, cathartic.

Built with **Next.js 15**, **TypeScript**, and **Tailwind CSS 4**.

## Architecture

- **Design & UI** — Tailwind CSS 4 with a custom dark theme (Impeccable.style-ready)
- **Database** — Superpowers (https://github.com/obra/superpowers) with JSON fallback
- **Deployment** — Vercel-ready

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Environment Variables

| Variable | Default | Description |
|----------|---------|-------------|
| `SUPERPOWERS_API_URL` | `http://localhost:3000` | Superpowers instance URL |
